# Claude Code Tricks

Quick reference for everyday shortcuts and commands.

## Commands

| Trick | What it does |
|-------|--------------|
| `! <command>` | Run a shell command directly yourself (Claude won't run it for you) |

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl` + `←` / `→` | Skip one word at a time |
| `Home` / `End` | Jump to start / end of the line |
